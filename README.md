---

### Abstract
Modern frontier foundation models exhibit severe epistemic drift, reward-hacking, and hallucinations when prompted with unconstrained or maximalist objectives. **Nova Conscientia** formalizes a cybernetic, dual-channel oversight loop that decouples generative proposal drive from hard invariant checking, grounded by human navigational intuition.

Originally developed through extensive empirical experimentation in galactic kinematics, numerical PDE solvers, and formal interactive theorem proving, this repository translates those findings into pure computer science, distributed agent runtime architectures, and formal alignment mechanisms.

---

### The Trinity Architecture
1. **The Intuitive Navigator (Human / RY)**: Directional compass, edge-of-distribution questions, and empirical ground-truth anchor.
2. **Persistent Cognitive Memory (Chyren)**: Monotonic state ledger, vector memory, graph topologies, and immutable audit logs surviving context flushes.
3. **Heterogeneous Swarm Execution Engine (The gAIng)**: Parallelized, specialized model workers cross-auditing proposed outputs via adversarial consensus.

---

### Core Components
- `core/`: Dual-channel variational action runtime, Anti-Drift Cognitive Control Loop (ADCCL), and information-theoretic clipping gates.
- `verification/`: AST invariant compilers, Lean 4 deductive theorem proving bridges, and multi-agent peer review harnesses.
- `benchmarks/`: Empirical evaluations testing baseline unconstrained LLMs against dual-channel swarm systems.
- `fellowship/`: Formal Anthropic Fellows Program research proposal and technical manifesto.
